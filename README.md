# Product Management — JSP & Servlet Final Exam

Dự án Java 17/Maven WAR quản lý sản phẩm (CRUD) sử dụng Servlet, JSP, JDBC và MySQL.

Chạy `database.sql` trên MySQL trước khi build bằng `mvn clean package`, triển khai `target/product-management.war` lên Tomcat 10.1+ và mở `/product-management/products`.

File ZIP bài nộp: `MSSV_FinalExam.zip` (thay MSSV bằng mã sinh viên của bạn khi nộp).
